# Source provenance

Build intent: user conversation, especially function + embodied, five coupled dimensions, recursive primitives, retained history, three doors, articulated movement, and later Unity integration.

Read source documents:

- System architecture, ontology, swarm mechanics, grammar, and research drafts: https://docs.google.com/document/d/1m4jCA-T-KntEXQ137pYEbaVQns6Ga36-pwCmH51DYbA/edit
- Causal graph tables and later terminology/frame clarifications: https://docs.google.com/document/d/13Q1W7lXzpJq7AZtlcDadUp21BnUjwS2ISusXGskjgnk/edit
- Companion Engine specification and illustrative Python code: https://docs.google.com/document/d/1pCmJHeJ4AUcrnzjsjGDOdCQdZjoLa-wpBjl5AcWfOlc/edit
- Black Book, dimensional discussion, printed pp.5 and 109–120: https://drive.google.com/file/d/1L7VD2PkU1yv-XDFKD2uNdPvcZYXUNr3D/view

The private source books and document extracts are not embedded in the distributable app.

Recovered runtime: supplied `Cynthia_Morph_Unified_Build_1.zip`, prefix `Morphing-Swarm-5D/server/dream/vendor/pure-synthia-swarm-body/`. Original recovered files are unchanged.

Actively reused modules under `src/synthia/semantic-mesh/`:

- `mesh/mesh.js`: AutomataMesh, typed-port connection contracts, five relation projections.
- `mesh/packet.js`: StatePacket.
- `automata/automaton.js`: execution lifecycle, traces, ledgers.
- `state-space/addressing.js`: King Wen binary mapping only. Its global address codec is deliberately not used for natal charts.

Imported automaton dependencies provide named transitions and trace sound/color metadata. They do not define the new canonical When/Where mapping.

Third-party renderer: Three.js 0.170.0 from https://unpkg.com/three@0.170.0/build/three.module.min.js; MIT license in vendor/three/LICENSE. Standalone bundling uses esbuild 0.25.0 as a temporary build tool, not a runtime dependency.

No Gen-Swarms, LucidLyra, SceneWiz3D, MiroFish, or GPTSwarm model/code is included. Those references inform longer-term design and are not claimed as implemented capabilities.
