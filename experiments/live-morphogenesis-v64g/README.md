# Live Morphogenesis v64g

Run `node test_two_environments.mjs` from this folder. To run the browser demo, serve this folder with `python3 -m http.server 8000` and open `http://localhost:8000/two-environments.html`.

This checkpoint contains the runnable app and grid-world experiment from Claude's Little Miracles v64g. It preserves the Function/Form units and uses host health to evaluate generated descendants. The full Lean distribution and its research-only assets are separate from this experiment. v64o integration remains open.
